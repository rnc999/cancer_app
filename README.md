# がん罹患リスク予測

年齢・性別と生活習慣（たばこ・お酒・体格・塩分・運動・野菜）を入力すると、
今後10年（または20年）の間にがんと診断される確率を部位ごとに予測する Streamlit アプリです。

## 仕組み

1. **機械学習モデル**：全国がん登録の年齢階級別罹患率で学習した勾配ブースティングで、
   年齢・性別・部位ごとの平均的な罹患率を予測（`cancer_model.ipynb`）
2. **生活習慣の補正**：日本人を対象とした研究で報告された相対リスクを掛ける。
   各選択肢を選ぶ人の割合で、平均的な人が 1 倍になるようにそろえてから掛けている（`data/risk_factors.csv`, `data/prevalence.csv`）
3. 1年ごとの罹患率を足し合わせて、期間内に診断される確率にする

学習用に作ったもので、医学的な診断ではありません。

## ファイル構成

- `app.py` : Streamlit アプリ
- `cancer_model.ipynb` : 前処理・モデルの学習・評価に使ったノートブック
- `data/risk_factors.csv` : 生活習慣ごとの相対リスクと出典
- `data/prevalence.csv` : 各選択肢を選ぶ人の割合と出典
- `models/model.pkl` : 学習済みモデル
- `data/raw/cancer_incidenceNCR(2016-2023).xls` : 元データ

## 出典

- 国立がん研究センターがん情報サービス「がん統計」（全国がん登録） https://ganjoho.jp/reg_stat/statistics/data/dl/index.html
- 相対リスク：国立がん研究センター 多目的コホート研究（JPHC Study）の成果、喫煙とがん死亡の3コホート併合解析、
  「生活習慣によるがんの相対リスク」表（各値の出典は `data/risk_factors.csv` の source 列）
- 喫煙・飲酒・肥満の割合：厚生労働省「国民健康・栄養調査」（令和4年・令和6年 ほか）。公表値がないものは仮定（`data/prevalence.csv` に明記）
